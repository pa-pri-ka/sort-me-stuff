# Sort Me Stuff

Small, ongoing project to practice my Python. The name is to be pronounced using Groundskeeper Willy's Scottish accent. I love Scottish accents!

# Developers

## Run the application

Assuming ou have Python 3 installed on your machine:

```powershell
# install pipenv
pip install --user pipenv
# activate the virtual environment
pipenv shell
# install the requirements
pipenv install
# run the thing
pipenv run py .\app\sortmestuff.py
# go get some whisky
ls whisky | grep "^Scottish" > me_belly.txt
```

## Work in VS Code

From the root path, open sortmestuff.py and run it in either debug or non-debug mode. **You have to be in the sortmestuff.py editor tab**. 

The debug mode is obviously the most important bit, since you'll be able to debug the code using VS Code's own debugger.
