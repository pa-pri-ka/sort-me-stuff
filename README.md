# Sort Me Stuff

Small, ongoing project to practice my Python. The name is to be pronounced using Groundskeeper Willy's Scottish accent. I love Scottish accents!

The usual useful stuff:

```powershell
# setup the virtal environment (if not done already)
python -m venv venv
# activate the virtual environment
.\venv\Scripts\activate
# install the requirements
pip install -r .\requirements.txt
# run the thing
py .\sortmestuff.py
# go get some whisky
ls whisky | grep "^Scottish" > me_belly.txt
```
